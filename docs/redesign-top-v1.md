# THE REV. トップページ改修 指示書 v1

## 目的と前提
therev-lab.com のトップページを、サービスの横並びから「人の悩み」を主役にした構成に組み替える。目的は、知人以外からの体験申込を増やすこと。
- 位置づけ：この指示書は v1。文案の一部（特に「こんなときに」）は一般的な利用者の声をもとにした仮説で、後から差し替える。
- 対象範囲：トップページのみ。下層ページ（料金・トレーナー・リカバリー・アクセス・コラム）は変更しない。

## 決定事項
ページ全体を「頑張っているのに、身体が良くなっている実感がない」人に向けて書き、その答えとして「鍛える・整える・回復する」を見せる。
- 鍛える：筋力・体力をつける。パーソナルトレーニング、パーソナルボクシング（楽しく鍛える選択肢）
- 整える：フォームを整え、その日の状態に合わせて強度を調整する。トレーナーの指導の仕方そのもの
- 回復する：鍛えた後に休む時間をつくる。酸素ルーム（主役）、DENBA Health（補足扱い）

設計ルール：
1. 悩みは一文で言い切る。複数の悩みを並べてぼかさない
2. 「悩み → 答え」を1対1でつなぐ（悩み01→鍛える、02→整える、03→回復する）
3. ファーストビューからFAQまで、同じ一人に話しかける

### 2. Empathy（悩み）
- 見出し：頑張っているのに、身体が良くなっている実感がない。
- リード：それは、努力が足りないからではないかもしれません。

## 表現ルール
酸素ルーム・DENBAは「効果」ではなく「時間と過ごし方」で語る。
- 使わない言葉：疲労回復、疲れが取れる、睡眠が良くなる、体調を整える、頭がクリアになる、肩こりが楽、寝不足、など効果を連想させる表現
- 使ってよい言い方：休む時間をつくる、静かに過ごす、横になる、着衣のまま、30分から、トレーニング後にそのまま利用できる
- 「整える」はフォームや強度の調整という行動の表現にとどめ、専門的な評価や診断に読める書き方はしない
- 「身体が良くなっている実感」はお客様の悩みとしてのみ使い、店側の約束として書かない
- 減量の数値や医療的な効果を約束する表現は使わない
- お客様の声には「感じ方には個人差があります」を必ず添える
- トーン：静かで言い切る。英語ラベル＋日本語見出しの形式を維持。感嘆符は使わない

## 変更しないもの
- メタ情報：title、meta description、OGP・Twitterカード（画像・alt含む）、canonical、JSON-LD
- 計測：GTM（head内スクリプトとnoscript）、予約リンクのUTM（7か所の utm_content と data-track / data-placement を維持）。新しいCTAを置く場合は新しい utm_content を付け、運営側に共有する
- アクセシビリティ：skip-link（「本文へ進む」）、画像のalt（新しい写真にも内容が分かるaltを付ける）
- 法務リンク：/privacy.html、/legal.html、/terms.html
- 料金・営業時間・住所などの事実情報（変更は運営側の確認後のみ）
- 既存の注記：「外部予約ページへ移動します」「感じ方には個人差があります」
- 触ってよいのはトップページ関連のファイルのみ。Vercel側のAPI、管理画面、ブログの仕組み、下層ページ、ビルド・デプロイ設定は変更しない

## 役割分担と運用
- 運営（服部）が決める：ターゲット・悩み・文案・事実情報
- 構築担当が決める：レイアウト・余白・配色・アニメーション
- 運営が用意するもの：指導中の実写写真、体験当日の所要時間・持ち物、FAQ「耳」の回答
- 「こんなときに」は、体験者へのヒアリングやSNSの反応をもとに、後日差し替える（v1 → v2）

## 進め方
- 段階1：ファーストビューとEmpathyの文言差し替えのみ（写真は現状のまま）
- 段階2：「こんなときに」、Trainerの追記、FAQの追加
- 段階3以降：新セクション追加、並び替え、写真・お客様の声のテキスト化
- 1回の作業で変更するのは1セクションまで。変更のたびに、何を変えたかと「変更しないもの」が残っていることを報告する
