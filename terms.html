会員規約・利用規約

本規約は、ファルクサービス株式会社（THE REV. CONDITIONING LAB. を運営。以下「当社」といいます。）が提供するサービスの利用条件を定めるものです。当ジムをご利用の際は、本規約の内容をご確認のうえ、ご同意いただきます。

制定日：2026年7月18日　／　最終改定日：2026年7月22日

01第1条（目的）

本規約は、ファルクサービス株式会社（以下「当社」といいます。）が運営する THE REV. CONDITIONING LAB.（以下「当ジム」といいます。）において、当社が提供するパーソナルトレーニング、メニュー作成、食事アドバイス、コンディショニングサービス、施設利用その他これらに付随するサービスの利用条件を定めるものです。

02第2条（適用範囲）

  1. 本規約は、当ジムを利用するすべての会員、ビジター、体験利用者、同伴者、未成年利用者その他当社が利用を認めた者に適用されます。
  2. 料金表、申込内容、健康申告、各種同意事項、プライバシーポリシー、キャンペーン条件その他当社が別途定める表示または案内は、本規約の一部を構成します。
  3. 本規約と個別の申込内容、料金表、同意事項等の内容が異なる場合、個別に明確な定めがあるものが優先されます。
  4. 会員または利用者が、入会申込時、予約時、サービス申込時その他当社が指定する方法により本規約に同意した場合、本規約に同意したものとします。
  5. 本規約にかかわらず、特定商取引法、消費者契約法その他法令により別段の定めがある場合は、当該法令が優先されます。

03第3条（手続窓口）

  1. 退会、コース変更、予約変更、キャンセル、休会相談その他の正式な手続は、店頭または公式LINEにより行うものとします。
  2. Instagram DMその他SNSは、正式な手続窓口には含まれません。
  3. 公式LINEの不具合、通信障害その他やむを得ない事情により、店頭および公式LINEでの手続がいずれも困難な場合に限り、会員は電話により当社へ申し出ることができます。この場合の電話は、正式な手続窓口ではなく、非常時の予備的な連絡手段として取り扱います。

04第4条（営業時間等）

  1. 当ジムの営業時間、定休日、最終受付時間その他営業に関する事項は、店頭掲示、公式LINE、ホームページ、料金表その他当社が定める方法により案内します。
  2. 当社は、臨時休業、営業時間変更、設備点検、研修、災害、交通機関の乱れその他運営上必要と判断した場合、営業時間または営業日を変更することがあります。

05第5条（会員資格）

会員または利用者は、以下の条件を満たすものとします。

  • 本規約、健康申告、各種同意事項および当社の案内に同意していること
  • 医師等から運動を禁止または制限されていないこと
  • 健康状態、既往歴、服薬状況、痛み、不調その他安全に関わる事項を正確に申告できること
  • 反社会的勢力に該当せず、これらと関係を有しないこと
  • 他の会員、利用者、スタッフおよび近隣に迷惑をかけないこと
  • 当ジムの施設、設備、備品およびブランド価値を尊重できること

06第6条（未成年者の利用）

  1. 未成年者が当社のサービスを利用する場合、親権者または法定代理人の同意を必要とします。
  2. 前項の同意は、当社が指定する書面、申込画面、公式LINEその他記録に残る方法により取得するものとします。

07第7条（利用をお断りする場合）

当社は、以下のいずれかに該当すると判断した場合、入会、利用、予約または継続利用をお断りすることがあります。

  • 医師等から運動または当社サービスの利用を禁止または制限されている場合
  • 発熱、強い倦怠感、めまい、胸痛、息切れ、強い痛み、感染症の疑いその他体調不良がある場合
  • 飲酒後または酒気帯び状態である場合
  • 健康申告に虚偽、未申告または重大な漏れがある場合
  • 暴力、暴言、威圧、ハラスメント、勧誘、迷惑行為等がある場合
  • 無断キャンセルまたは当日キャンセルを反復する場合
  • 施設、設備、備品を損傷するおそれがある場合
  • その他、当社が安全上または運営上不適切と合理的に判断した場合

08第8条（提供サービス）

当社は、当ジムにおいて、以下のサービスを提供します。

  • パーソナルトレーニング
  • メニュー作成・スポット利用
  • 食事アドバイス
  • コンディショニングサービス
  • 体験利用
  • その他当社が別途定めるサービス

09第9条（パーソナルトレーニング）

  1. パーソナルトレーニングは、会員の目的、体力、運動経験、身体状態等を踏まえて、当社が運動指導を行うサービスです。
  2. セッション時間、回数、料金、利用条件は、料金表、申込画面または個別申込内容に定めます。
  3. 当社は、安全確保のため、当日の体調、痛み、疲労度、動作状態等に応じて内容を変更することがあります。
  4. 会員は、セッション中に痛み、違和感、めまい、吐き気、息苦しさ、強い疲労感その他異常を感じた場合、直ちにトレーナーへ申告するものとします。

10第10条（メニュー作成・スポット利用）

  1. メニュー作成・スポット利用は、トレーニングプログラムの設計、フォーム確認、サポート等を行うサービスです。
  2. メニュー作成・スポット利用は入会金不要とします。
  3. 各種プランの利用時間枠、有効期限および利用条件は、料金表、申込画面または個別申込内容に定めます。
  4. メニュー作成サービスについて、当社が作成に着手した後に利用者都合で解約された場合、着手済み業務に相当する対価および合理的費用を控除し、残額がある場合は精算します。
  5. 納品完了後は、利用者都合による返金を行いません。ただし、当社の責めに帰すべき事由または法令上返金が必要な場合は、この限りではありません。

11第11条（食事アドバイス）

  1. 食事アドバイスは、一般的な生活習慣改善、栄養バランス、食習慣の見直しに関する助言を行うサービスです。
  2. 食事アドバイスは、月額プランをご契約の会員を対象とする月額オプションサービスとして提供します。料金、申込方法その他の利用条件は、料金表、申込画面または個別申込内容に定めます。
  3. 当社は、会員が申告または記録した食事内容等に基づき、1日1回を目安としてフィードバックを行います。
  4. フィードバックは、営業時間内に行うものとし、即時返信または一定時間内の返信を保証するものではありません。
  5. 会員からの申告または記録がない日その他フィードバックの前提を欠く場合、当該日のフィードバックは行いません。この場合においても、当該日分の料金の返金、繰越または振替は行いません。
  6. 本オプションのみを単独で契約することはできません。月額プランの退会または終了に伴い、本オプションも同時に終了します。
  7. 食事アドバイスは、医療行為、治療、診断、疾病管理、栄養療法または医師・管理栄養士等による専門的医療指導を目的とするものではありません。
  8. 疾病、投薬、摂食障害、糖尿病、腎疾患、肝疾患、妊娠中その他医学的管理を要する状態にある場合、利用者は医師等の専門家に相談するものとします。

12第12条（コンディショニングサービス）

  1. コンディショニングサービスは、酸素ルームおよびDENBAを利用し、利用者が休養、リフレッシュおよび身体のコンディショニングを行うための環境を提供するサービスです。
  2. コンディショニングサービスは、医療行為、診断、治療、疾病の改善または予防を目的とするものではありません。
  3. 当社は、コンディショニングサービスについて、疲労回復、睡眠、痛み、体調、身体機能その他特定の効果または成果を保証するものではありません。
  4. 利用者は、コンディショニングサービスの利用前に、健康状態、既往歴、服薬状況、妊娠の有無その他安全管理上必要な事項を正確に申告し、当社が別途定める利用同意書および注意事項に同意するものとします。
  5. 当社は、利用者の健康状態、申告内容、当日の体調その他の事情から、安全上不適切であると合理的に判断した場合、利用の全部または一部を中止、変更またはお断りすることがあります。
  6. コンディショニングサービスの利用時間、料金、回数券の有効期限、予約条件その他の利用条件は、料金表、申込画面、利用同意書または個別申込内容に定めます。

13第13条（成果保証の否定）

当社は、適切な指導および環境提供に努めますが、体重減少、筋肉量増加、体型変化、姿勢改善、痛みの改善、睡眠の質の向上、競技力向上その他特定の成果を保証するものではありません。

14第14条（料金）

  1. 当社の入会金、月会費、回数券、都度利用料、メニュー作成料その他の料金は、当社が別途定める料金表によります。
  2. 料金は、当社が必要と判断した場合、事前告知のうえ変更されることがあります。
  3. 月額プランの料金を変更する場合、当社は変更後料金、適用開始日その他必要な事項を事前に通知します。
  4. 既に契約済みのサービスについて、料金変更を遡及して適用することはありません。

15第15条（入会金）

  1. 当社の入会金は、料金表によるものとします。
  2. 入会金の要否および金額は、サービスまたはプランごとに料金表に定めるところによります。入会金を要しないサービスまたはプランについては、入会金は発生しません。
  3. 入会金は、会員都合による退会、解約または未利用の場合、原則として返金しません。ただし、当社の責めに帰すべき事由または法令上返金が必要な場合は、この限りではありません。

16第16条（支払方法）

  1. 当社の支払方法は、現金、クレジットカード、口座振替、PayPayその他当社が指定する方法とします。
  2. 月額プランの継続決済方法は、会員と当社が合意した方法によります。
  3. 決済不備、残高不足、カード利用停止、口座振替不能等により支払いが確認できない場合、当社はサービス提供または予約受付を制限することがあります。

17第17条（月額プランの決済・自動更新）

  1. 月額プランは、毎月20日に翌月分の月会費を決済するものとします。
  2. 月額プランは、退会手続が完了しない限り、1ヶ月ごとに自動更新されます。
  3. 入会時の初回月会費の金額、対象期間および次回決済日は、料金表、申込画面または個別申込内容に定めます。
  4. 食事アドバイス（月額オプション）その他の月額オプションを利用する場合、その料金は、月会費とあわせて前各項に定める方法により決済します。
  5. 月額オプションは、月額プランの契約が終了した場合、これに伴い終了します。

18第18条（月額プランの未消化分）

  1. 会員都合による月額プランの未消化分については、原則として繰越、返金、振替を行いません。
  2. ただし、当社都合、臨時休業、災害、交通機関の大幅な停止、医師の診断を伴う急な傷病、法令上返金が必要な場合、その他当社が合理的と認める事情がある場合は、この限りではありません。

19第19条（回数券・チケット）

  1. 回数券、チケット、月額プランその他の利用権は、購入者本人のみ利用でき、第三者への譲渡、貸与、名義変更、転売、換金はできません。
  2. 回数券およびチケットには、券種ごとに料金表に定める有効期限を設けるものとし、有効期限は、購入日または更新日を起算日とします。
  3. 有効期限を経過した未利用分は失効し、繰越、返金、振替、期限の延長は行いません。ただし、当社都合、災害、医師の診断を伴う急な傷病、法令上返金が必要な場合、その他当社が合理的と認める事情がある場合は、この限りではありません。
  4. 定期見直し年間チケットその他、定期的な役務の提供を目的とするチケットについては、その目的に照らし、料金表に定める利用間隔を目安として利用するものとし、未利用分を契約終了前に連続して消化することはできません。利用間隔は、会員の目的および進捗に応じて当社と会員が協議のうえ調整します。
  5. 回数券およびチケットの中途解約時の未利用分の取扱いは、料金表、重要事項説明または個別申込内容に定めます。
  6. 当社都合、法令上返金が必要な場合、その他当社が合理的と認める場合は、未提供分について適切に精算します。

20第20条（完全予約制）

  1. 当社のサービスは、原則として完全予約制とします。
  2. 予約は、当社が指定する方法により行い、当社が承認した時点で成立します。

21第21条（予約変更・キャンセル）

  1. 予約の変更またはキャンセルは、予約日前日の23:59までに、店頭または公式LINEにより行うものとします。
  2. 予約日前日の23:59を過ぎた変更またはキャンセルは、当日キャンセルとして扱います。
  3. 当日キャンセルは、当該予約分を1回消化とします。
  4. 公式LINEによる連絡は、当社が確認可能な状態で送信された時刻を基準として判断します。
  5. Instagram DMその他SNSでの連絡は、正式な予約変更・キャンセル手続とは扱いません。

22第22条（無断キャンセル）

  1. 会員が事前連絡なく予約時間に来店しなかった場合、無断キャンセルとして、当該予約分を1回消化とします。
  2. 無断キャンセルが発生した場合、当社は注意、予約受付の制限または事前決済を求めることがあります。
  3. 無断キャンセルが反復し、または悪質であると合理的に判断した場合、当社は利用停止または契約解除を行うことがあります。

23第23条（遅刻）

  1. 会員が予約開始時刻に遅れた場合、セッションは残り時間内で実施します。
  2. 遅刻による終了時刻の延長、返金、振替、繰越は行いません。
  3. 遅刻時間が長く、十分なサービス提供が困難と判断した場合、当該予約を実施せず、1回消化とすることがあります。

24第24条（体験利用）

  1. 初回体験は、1人1回限りとします。
  2. 体験利用後、利用者の明示的な申込みなく、月額プランへ自動移行することはありません。
  3. 体験予約のキャンセルについて、キャンセル料は発生しません。
  4. 体験予約を無断キャンセルした場合、その後の体験予約または利用をお断りすることがあります。

25第25条（退会）

  1. 月額プランの退会を希望する会員は、退会希望月の前月末日までに、店頭または公式LINEにより退会申請を行うものとします。
  2. 前項の期限までに退会申請が完了した場合、退会希望月の末日をもって退会となり、退会希望月の翌月分以降の決済を停止します。
  3. 退会申請後も、退会成立日までは、支払い済みの契約内容に従って当ジムを利用できます。
  4. 退会申請が期限を過ぎた場合、次回更新分の月会費が発生することがあります。
  5. 退会申請は、当社が受付完了を通知した時点で完了します。ただし、会員が期限内に適正な方法で退会申請を送信または申し出たことを確認できる場合、その送信時または申出時を申請時刻として扱います。

26第26条（コース変更）

  1. 月額プランのコース変更を希望する会員は、変更希望月の前々月末日までに、店頭または公式LINEにより申請するものとします。
  2. 前項の期限までに申請が完了した場合、変更希望月より変更後のコースを適用します。
  3. 申請期限を過ぎた場合、コース変更の適用は翌々月以降となることがあります。
  4. コース変更申請は、当社が受付完了を通知した時点で完了します。ただし、会員が期限内に適正な方法で申請を送信または申し出たことを確認できる場合、その送信時または申出時を申請時刻として扱います。
  5. 食事アドバイス（月額オプション）その他の月額オプションの申込みおよび解約は、適用希望月の前月末日までに、店頭または公式LINEにより申請するものとします。この場合、前項を準用します。
  6. 月額オプションの未消化分については、第18条の定めを準用します。

27第27条（休会）

  1. 当社は、原則として休会制度を設けません。
  2. ただし、傷病、妊娠、長期出張、災害その他やむを得ない事情がある場合、当社が合理的と認める範囲で個別に協議します。

28第28条（利用停止・契約解除）

  1. 当社は、会員または利用者が以下のいずれかに該当し、客観的かつ合理的な理由により利用継続が困難と判断した場合、利用停止、予約制限、契約解除その他必要な措置を行うことがあります。
    • 本規約に違反した場合
    • 料金の未払いがある場合
    • 無断キャンセルまたは当日キャンセルを反復した場合
    • 健康申告に虚偽または重大な未申告があった場合
    • 暴力、暴言、威圧、ハラスメント、迷惑行為、勧誘行為等があった場合
    • 施設、設備、備品を故意または重大な過失により損傷した場合
    • 当社、当ジム、スタッフ、他会員、利用者等の信用、名誉、プライバシーを害する行為をした場合
    • 反社会的勢力に該当し、または関係していることが判明した場合
    • その他前各号に準ずる重大な事情がある場合
  2. 前項の措置を行う場合、緊急性がある場合その他事前通知が困難な場合を除き、当社は事前通知または是正の機会を設けるよう努めます。

29第29条（健康申告）

  1. 会員および利用者は、初回利用時および当社が求めた場合、健康申告を行うものとします。
