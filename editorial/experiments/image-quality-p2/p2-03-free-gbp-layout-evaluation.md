# p2-03｜DENBA Health GBP 4:3 既存画像・無料レイアウト比較

**検証日**: 2026-10-15 JST  
**分類**: P2 Offline Experiment / non-production / no billable model calls  
**対象実行**: [R2 rejected run #38659378986](https://github.com/maxi001maxi/the-rev-website/actions/runs/38659378986)  
**結果**: **有望なレイアウト候補を特定。独立QC合格は未確認。**

## 背景

R2のIndependent Visual QCは人物視覚注意量55%（基準58–75%）、背景が強く鮮明、GBP 4:3の白いフェードが女性の口元と胸元を隠すことを理由に不合格。シーンのTHE REV.受付・実DENBA機器・自然な顧客行動は維持されていた。R1も52%で不合格。現行Aは強いビジュアルなので現時点では維持する。

## 使用した既存画像

1. R2 GBP 400×300 実プレビュー（GitHub run #38659378986 artifact）
2. R2 横長サムネイル 400×225 実プレビュー（同）
3. 現行A 正式画像1200×675（同runの `paired/p2-03/baseline.jpg`）

※生成されたテキスト/フェードのない原画は、失敗runのartifact内に含まれていなかった。したがって本試験は、元のラスタ画像に焼き込まれた情報を無理に復元せず、安全な非破壊再配置に限定した。

## 無料で作成した5案

| 案 | 既存画素の扱い | 見た目の評価 |
|---|---|---|
| R2 GBPそのまま | 以前の完成版 | 顔と胸元に追加GBP白フェードが重なるため不合格 |
| R2横長→4:3アイボリー余白 | 元画像全部を中央に保持 | 顔への**追加**フェードがなくなる。ただしR2人物の存在感不足は未解決 |
| R2横長→4:3端色延長 | 元画像全部を保持 | 上下の延長が不自然。採用非推奨 |
| **現行A→4:3アイボリー余白** | **正式A画像全部を保持** | **最有望な検証案**。顔・DENBA・見出しを損なわず、変な白ヴェールを新規配置しない |
| 現行A→4:3端色延長 | 元画像全部を保持 | にじみ・伸長感が残り非推奨 |

全案で新規画像生成モデル/API呼出し **0回**。本番サイト・元サムネイル・GitHub Actions・QA閾値変更 **なし**。

## 機械的に確かめた不変条件

- 入力横長（A 1200×675 / R2 400×225）を1200×675へリサイズした中央領域が4:3の1200×900出力中の `y=113..787` と**バイトではなく画素として完全一致**することをnumpy/Pillowで確認。左右のトリミング **0px**。
- 4:3出力 1200×900およびスマホ表示用400×300を作成。
- 元の人物、機器、見出し、背景を新しく描いていない。上下112/113pxの薄いアイボリー余白のみ。
- 横長にもともと含まれていた白いフェード自体は元画像の一部として保存される。**「完全除去した」とは言わない**。

## 最終判断と未完了

**推奨**: 現行Aから「元画像を切らず上下余白を追加」するGBP専用のオフライン候補を、次の独立QCの対象にする。

**未確認**: 人物への注意量が58%以上になるか／独立Visual QC・GBP safe-area・320pxの文字可読性がすべて合格するか／余白の存在が実運用で許容できるか。

この無料試験だけで「QC PASS」「本番公開可能」「R2の人物問題を解決」とは言えない。R2を採用したり、原画がないのに顔のフェードを画像編集で除去したと称したりしない。
